# BARNES — аренда для собственников

Публичный пакет страницы `arenda_sobstvennikam`, вынесенный отдельно от главной страницы и других лендингов BARNES.

## Структура

- `arenda_sobstvennikam/` — готовая страница целиком со всеми локальными изображениями, шрифтами и runtime-файлами.
- `src/` — читаемые доработки страницы: CSS, JavaScript и handoff для разработчика.
- `blocks/` — каждый видимый блок страницы в отдельной папке.
- `shared/` — общий UI-кит и правила, от которых зависят блоки.
- `tools/extract_blocks.py` — повторяемый экспорт блоков из актуальной страницы.

## Запуск полной страницы

```bash
python3 -m http.server 4183
```

После запуска откройте:

```text
http://127.0.0.1:4183/arenda_sobstvennikam/
```

## Как перенести отдельный блок

1. Выберите папку в `blocks/`.
2. Скопируйте `fragment.html` в нужную страницу.
3. Подключите `src/reference-ui-overrides.css` после базовых стилей BARNES.
4. Подключите `src/reference-ui-behavior.js` с `defer`, если блоку нужны интерактивность или динамические улучшения.
5. Перенесите только перечисленные в локальном `README.md` изображения либо сохраните структуру `arenda_sobstvennikam/assets`, `arenda_sobstvennikam/pictures` и `arenda_sobstvennikam/fonts`.

HTML-фрагменты экспортируются из канонического `arenda_sobstvennikam/index.html`. Они не являются второй вручную редактируемой копией: после изменения страницы запустите `python3 tools/extract_blocks.py` и закоммитьте обновлённые фрагменты.

## Важно

- Каноническая рабочая страница остаётся в `arenda_sobstvennikam/` и сохраняет исходные абсолютные пути.
- Блоки не зависят друг от друга по порядку, но используют общий UI-кит.
- Оригинальные права на бренд, изображения и материалы BARNES принадлежат их правообладателям.
