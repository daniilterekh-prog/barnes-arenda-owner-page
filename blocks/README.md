# Каталог блоков

| Папка | Блок | Корневой селектор |
|---|---|---|
| `01-hero-header` | Хедер внутри hero | `.site-header` |
| `02-sticky-header` | Второй хедер после прокрутки | `.owner-sale-sticky` |
| `03-hero` | Hero страницы | `.owner-sale-hero` |
| `04-presentation` | Стратегия презентации | `.owner-sale-presentation` |
| `05-team` | Единая команда BARNES | `.owner-sale-services` |
| `06-barnes-moscow` | BARNES / Москва | `.about-company` |
| `07-exclusive` | Преимущества эксклюзивной работы | `.owner-sale-exclusive` |
| `08-consultation` | CTA с Русланом и формой | `.catalog-contact` → `.catalog-consultation` после улучшения |
| `09-property-links` | Перелинковка с изображениями | `.owner-sale-types` |
| `10-newsletter` | Email-рассылка | `.newsletter-cta` |
| `11-footer` | Footer | `.site-footer` |
| `12-floating-expert` | Плавающий контакт эксперта | `.floating-expert` |

В каждой папке находятся `fragment.html`, локальный `README.md` и `block.json`. Общие CSS/JS и ассеты специально не дублируются.
